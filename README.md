# codealpha_tasks
Student Grade Tracker:
A Java program to manage student grades.

Features:
Input and manage student marks
Calculate average, highest, and lowest scores
Use Arrays or ArrayList for data storage
Display summary report of all students
Console-based or GUI-based interface

Technologies Used: 
Java (Core Java) – Main programming language used for development
Object-Oriented Programming (OOP) – Classes and objects to manage student data
Java Collections Framework – ArrayList for storing student records dynamically
Scanner Class – For taking user input from console
Basic Algorithms – To calculate average, highest, and lowest marks
Console-Based Interface – For user interaction (CLI application)
